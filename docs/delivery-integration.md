# Delivery integration status

Debre Birhan own-driver delivery is represented by zones, drivers, assignments, tracking numbers, and delivery events. Nationwide orders require an administrator quote and manual shipment creation until a courier contract is verified.

Do not assume public API coverage or prices for Ahununu, Ethiopian Postal Service, or other providers. Add adapters under `backend/src/delivery/` only after the provider confirms pickup coverage, rates, tracking, COD, settlement, and API documentation.
